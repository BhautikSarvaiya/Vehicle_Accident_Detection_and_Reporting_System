# Vehicle_Accident_Detection_and_Reporting_System
Developed a Vehicle Accident Detection and Reporting System using embedded systems technology to automatically detect vehicle accidents and provide immediate emergency notifications.

@Technologies & Components:

ESP32 Dev Module/Arduino Uno

MPU6050 Accelerometer & Gyroscope

NEO-6M GPS Module

SIM800L GSM Module

Arduino IDE

@Key Features:

Detects vehicle accidents using the MPU6050 accelerometer and gyroscope.

Retrieves the accident location through the GPS module.

Automatically sends an SMS containing the accident location to predefined emergency contacts.

Initiates an automatic phone call to emergency contacts for immediate attention.

Enables faster emergency response by reducing the need for manual intervention.

Compact and reliable embedded system designed for vehicle safety applications.
